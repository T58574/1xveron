# Veron ⚡

**Veron** — сверхбыстрая и удобная оболочка на **Rust** для управления терминальными сессиями Windows с эстетичным графическим интерфейсом в стиле **BridgeMind** и **Warp.dev**.

---

## 🌟 Ключевые возможности

1. **Сетка терминальных окон (1 \ 2 \ 3 \ 4 \ 5 \ 6 окон) со Slot Persistence**:
   - Быстрое переключение раскладок в 1 клик через пикер в верхнем баре:
     - `1`: Одиночный полноэкранный терминал.
     - `2`: Сплит 50/50.
     - `3`: 1 главное окно слева + 2 окна справа (стиль BridgeMind).
     - `4`: Классическая сетка 2×2.
     - `5`: 2 сверху + 3 снизу.
     - `6`: Сетка 2×3 (6 независимых инстансов).
   - **Фиксированные слоты (Slot-to-Session)**: окна не перепрыгивают и не сдвигаются при закрытии соседних сессий.

2. **Нативное ядро ConPTY (Windows Pseudo Console)**:
   - Реализовано на `portable-pty` от создателей WezTerm.
   - Прямой запуск `powershell.exe` (с флагом `-NoLogo`), `cmd.exe`, `wsl.exe`, `bash.exe` (Git Bash).
   - Безупречная поддержка UTF-8, ANSI VT100 escape-кодов, 24-bit TrueColor и псевдографики.
   - Защита от процессов-зомби: при закрытии сессии вызывается `taskkill /PID /T /F`, завершая все дерево дочерних процессов (Node, Python и др.).
   - Кольцевой буфер истории (scrollback buffer): при переключении окон или подключении с телефона сессия мгновенно отображает недавний вывод.

3. **Левый сайдбар управления сессиями (BridgeMind / Warp)**:
   - Группировка окон по воркспейсам с бейджами количества открытых терминалов.
   - Статус активности: пульсирующий зеленый индикатор `●` при выполнении команд.
   - Поиск по названию сессии, shell и текущей директории.
   - Виджет объема сохраненных скриншотов с кнопкой быстрой очистки в 1 клик.

4. **Вставка картинок и скриншотов прямо в терминал (`Ctrl+V` / Drag-and-Drop)**:
   - Сделал скриншот? Просто нажми `Ctrl+V` в окне терминала Veron или перетащи файл мышкой!
   - Бэкенд автоматически сохраняет картинку в папку `.veron/captures/screenshot_*.png`.
   - Путь к файлу моментально подставляется прямо в строку ввода терминала (или CLI-ассистента `agy`, `claude`), а на экране всплывает аккуратный тост.

5. **Мобильный «Диванный режим» (Local Wi-Fi Remote Control + LAN Security)**:
   - Встроенный сервер на `axum` слушает `0.0.0.0:4567`.
   - **Безопасность**: при старте генерируется 8-значный Auth Token. Неавторизованные устройства в Wi-Fi блокируются (`401 Unauthorized`).
   - В интерфейсе по кнопке «Phone Remote» отображается QR-код с уже вшитым токеном: навел камеру телефона — и сразу управляешь терминалом с дивана в 1 клик!
   - **Особенности мобильного режима**:
     - Сетка отключена: терминал развернут на 100% ширины для максимальной читаемости.
     - Верхний дропдаун для мгновенного переключения между сессиями ПК.
     - Нижний мобильный тулбар с клавишами, которых нет на виртуальных клавиатурах: `[ESC]`, `[TAB]`, `[CTRL+C]`, `[CTRL+Z]`, `[↑]`, `[↓]`, `[Clear]`.
     - Адаптация через `window.visualViewport`: терминал не уезжает при открытии клавиатуры.

6. **Дизайн и темы**:
   - Палитра Dark (глубокий матовый графит/zinc `#121316` / `#16171d`, не режущий глаза OLED) и Light.
   - Иконки Lucide / Material Design (полностью без цветных эмодзи).

## 🚀 Быстрый запуск

### 1. Запуск сервера и интерфейса
```powershell
# Запуск бэкенда на Rust (ConPTY + Axum)
npm run veron
```
После запуска:
- На ПК открой: `http://localhost:4567`
- На смартфоне в той же сети Wi-Fi: отсканируй QR-код в диалоге "Phone Remote".

### 2. Режим разработки с горячей перезагрузкой фронтенда (HMR)
```powershell
# Терминал 1: Запуск бэкенда
npm run veron

# Терминал 2: Запуск Vite Dev Server
npm run dev
```

### 3. Полная сборка релизного бинарника
```powershell
npm run build:all
```
Релизный файл будет сохранен в: `src-tauri/target/release/veron.exe`.
