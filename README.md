# Veron ⚡

**Veron** — сверхбыстрая, автономная и эстетичная десктопная оболочка на **Rust (Wry + Tao + ConPTY)** для управления терминальными сессиями Windows с дизайном уровня Apple в палитре **Cybran Yellow & Black** (глубокий обсидиан `#090a0d` + чистое янтарное золото `#f59e0b`).

Вдохновлен лучшими идеями **BridgeMind** и **Warp.dev**, но без оверинжиниринга, без «нейрослопа» и без навязанных облачных телеметрий.

---

## 🌟 Ключевые возможности

### 1. Единый автономный `.exe` (Single Portable Binary — 3.7 МБ)
- **Никаких установщиков и зависимостей**: весь фронтенд (HTML, CSS, JS-бандл, шрифты, иконки, XTerm) вшит прямо в бинарник через `rust-embed`.
- **Запуск в один клик**: просто запусти `veron.exe` на ПК.
- При запуске мгновенно открывается нативное графическое окно Windows на базе **Tao + Wry (WebView2)**, а в фоне поднимается сервер ConPTY и локальный Wi-Fi хаб.

### 2. Сетка терминалов (1 \ 2 \ 3 \ 4 \ 5 \ 6 окон) со Slot Persistence
- **Сегментированный переключатель 1–6**:
  - `1`: Одиночный терминал.
  - `2`: Сплит 50/50.
  - `3`: 1 главное окно слева + 2 окна справа (стиль BridgeMind).
  - `4`: Классическая сетка 2×2.
  - `5`: 2 сверху + 3 снизу.
  - `6`: Сетка 2×3 (6 независимых инстансов).
- **Slot Persistence**: фиксированные слоты — при закрытии окна соседние терминалы не скачут и не сдвигаются.
- **Интуитивный сплит**: кнопка `[+]` внутри карточки терминала автоматически расширяет сетку и запускает новый шелл.
- **Переименование по дабл-клику**: дважды кликни по названию терминала в шапке (например, переименуй `PowerShell` в `Vite Dev` или `Docker DB`), имя синхронизируется везде.

### 3. Быстрые скрипты и Командная палитра (`Ctrl+K` / `⌘K`)
- Вызывается по шорткату **`Ctrl+K`** или кнопке **Scripts** в шапке:
  - **Системные пресеты**: `Kill Port 4567`, `Top 5 CPU Processes`, `ipconfig`, `flushdns`.
  - **Git-пресеты**: `git status -s`, `git pull`, `git log graph`, `git diff --stat`.
  - **Dev-пресеты**: `cargo check`, `npm run build`, запуск скриншотов.
  - **Кастомные скрипты**: добавление своих команд с сохранением в `localStorage` и выбором мгновенного автозапуска (`Enter`).

### 4. Нативное ядро ConPTY и 100% чистый выход (Zero Zombies)
- Ядро на `portable-pty`: прямой запуск `powershell.exe` (с `-NoLogo`), `cmd.exe`, `wsl.exe`, `bash.exe` (Git Bash).
- **Кольцевой буфер скроллбэка (512 КБ)**: при переключении окон, сворачивании сетки или смене вкладок сессии **никогда не теряют вывод** и не прерываются.
- **Гарантированная зачистка процессов**: при нажатии на крестик окна `[X]` или `Ctrl+C` вызывается `taskkill /PID <pid> /T /F` со скрытым флагом `CREATE_NO_WINDOW`. Все дочерние процессы (Node, Vite, Python, Cargo) гарантированно удаляются из памяти, а порты освобождаются.

### 5. Мгновенный перехват скриншотов (`Ctrl+V` / Drag-and-Drop)
- Сделал скриншот? Нажми `Ctrl+V` прямо в окне терминала Veron или перетащи картинку мышкой:
  - Veron сохраняет файл в `.veron/captures/screenshot_*.png`.
  - Автоматически вставляет путь к картинке в строку ввода активного терминала (удобно для передачи пути в CLI-ассистентов `agy`, `claude` и т.д.).
  - В сайдбаре есть счетчик скриншотов, кнопка открытия папки в Проводнике Windows (`explorer.exe`) и кнопка полной очистки в 1 клик.

### 6. Мобильный «Диванный режим» (Couch Mode по Wi-Fi)
- Подключение с телефона по локальной сети: `http://192.168.x.x:4567?token=...` (QR-код доступен по кнопке *Phone Remote*).
- **LAN Security**: 8-значный Auth Token защищает от несанкционированного доступа из локальной сети (`401 Unauthorized`).
- **Специально для телефонов**:
  - Строго один полноэкранный терминал без сплитов (максимальная читаемость).
  - Верхний переключатель сессий ПК.
  - Нижний тулбар разработчика: `[ESC]`, `[TAB]`, `[CTRL+C]`, `[CTRL+Z]`, стрелки `[▲] [▼] [◀] [▶]`, `[Clear]`, `[↵]`.
  - Поле ввода команд с поддержкой виртуальной клавиатуры и отслеживанием `visualViewport`.

## 🚀 Как запускать

### Вариант 1. Запуск десктопного приложения (1 клик)
Просто запусти файл:
```powershell
.\veron.exe
```
*(Или в папке сборки: `src-tauri\target\release\veron.exe`)*

### Вариант 2. Запуск в режиме сервера (Headless / без GUI-окна)
Если нужен только бэкенд и доступ через браузер / телефон:
```powershell
.\veron.exe --server-only
```

### Вариант 3. Режим разработки с горячей перезагрузкой (HMR)
```powershell
# Терминал 1: Запуск Vite Dev Server (фронтенд)
npm run dev

# Терминал 2: Запуск бэкенда на Rust
npm run veron
```

## 🛠️ Сборка из исходников

```powershell
# 1. Установка фронтенд зависимостей
npm install

# 2. Сборка фронтенда
npm run build

# 3. Компиляция релизного бинарника на Rust (со вшитыми ассетами)
cargo build --release --manifest-path src-tauri/Cargo.toml

# 4. Копирование готового veron.exe в корень проекта
Copy-Item src-tauri\target\release\veron.exe .\veron.exe
```

## 🎨 Дизайн-код Cybran Yellow & Black
- **Background**: `#090a0d` (глубокий бархатистый обсидиан) / `#0c0d12` (карточки).
- **Accents**: `#f59e0b` / `#fbbf24` (янтарное золото, строгий сдержанный стиль без радужного нейрослопа).
- **Border Focus**: мягкое свечение `ring-1 ring-amber-400/70 border-amber-400/40`.
